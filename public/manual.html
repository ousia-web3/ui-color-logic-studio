사진을 넣고,
UI 색상으로 바꾸는 방법

대표색 추출부터 텍스트 대비, 상품·콘텐츠·배너 미리보기, 대량 검수와 개발용 내보내기까지 한 번에 설명합니다.

AI·API 키 불필요브라우저 내부 처리테스트 이미지 50장 포함

1. 프로그램 개요

UI 컬러 로직 스튜디오는 사진의 색을 그대로 복사하지 않고, 실제 UI에서 쓰기 좋은 역할별 색상으로 보정하는 도구입니다.

이미지 입력
→
후보색 추출
→
UI 안전 범위 보정
→
텍스트 대비 계산
→
CSS·JSON 출력
이미지는 서버나 AI 모델로 전송하지 않습니다. 색상 분석은 사용 중인 브라우저 안에서 수행됩니다.

2. 빠른 시작

이미지 넣기상단 영역에 JPG·PNG·WebP 파일을 끌어놓거나 ‘이미지 선택’을 누릅니다. 여러 장을 동시에 선택할 수 있습니다.
대표색 확인오른쪽 UI 팔레트에서 RAW KEY와 CORRECTED 값을 비교합니다. 후보색을 누르면 대표색을 교체할 수 있습니다.
문구와 템플릿 검수왼쪽에서 제목·설명·버튼 문구를 입력하고, 상품·콘텐츠·배너 유형을 전환해 실제 적용 모습을 봅니다.
보정 또는 승인채도·색온도·표면 틴트·최소 대비를 조정한 뒤 결과를 승인하거나 ‘보정 필요’로 기록합니다.
결과 내보내기‘CSS 복사’로 현재 팔레트를 복사하거나 ‘프로젝트 JSON’으로 이미지와 모든 분석 결과를 저장합니다.

3. 화면 구성

보정 로직

색의 분위기를 조정하는 프로필과 슬라이더가 있습니다.

텍스트 입력

라벨·제목·설명·메타 정보·버튼 문구를 실제 콘텐츠로 교체합니다.

라이브 미리보기

상품·콘텐츠·배너에서 이미지와 색이 자연스럽게 연결되는지 확인합니다.

UI 팔레트

역할별 색상과 HEX 값을 확인하고 직접 미세 조정합니다.

필름 스트립

여러 이미지 사이를 빠르게 이동합니다. 색 띠는 각 이미지의 대표색입니다.

배치 검수

여러 이미지의 결과를 한 화면에서 비교하고 승인 여부를 기록합니다.

4. 보정 설정

항목역할권장 사용
균형형대부분의 사진에 맞는 기본 보정처음 분석할 때
소프트채도와 대비가 부드러운 UI라이프스타일·뷰티·에디토리얼
볼드강한 채도와 선명한 강조색프로모션·이벤트·게임
다크어두운 표면을 중심으로 팔레트 생성다크 테마·영상 콘텐츠
채도 보정대표색의 선명도 조절색이 탁하거나 지나치게 강할 때
색온도따뜻한 색·차가운 색 방향 조절브랜드 분위기를 통일할 때
표면 틴트카드 배경에 대표색이 섞이는 정도본문 배경이 너무 진하거나 흐릴 때
최소 대비텍스트와 배경의 목표 명암비일반 본문은 기본값 4.5:1 권장
‘무채색·과노출 제외’를 켜면 흰 배경과 검은 그림자가 대표색으로 선택되는 현상을 줄일 수 있습니다.

5. 팔레트 결과 해석

역할사용 위치CSS 변수
Key대표 강조색, 배지--ui-key
On KeyKey 위의 텍스트--ui-key-foreground
Surface카드의 기본 바탕--ui-surface
Gradient A/B이미지와 본문 연결, 본문 배경--ui-gradient-top/bottom
Text/Muted제목·본문·보조 정보--ui-text-primary/secondary
Accent버튼·상태 강조--ui-accent
On AccentAccent 위의 텍스트--ui-accent-foreground
Border카드와 버튼 경계--ui-border

텍스트는 무조건 검정이 아닙니다. 각 배경에서 짙은 검정과 흰색의 대비를 비교해 더 읽기 좋은 색을 자동 선택합니다.

6. 상품·콘텐츠·배너 미리보기

상품

둥근 카드와 명확한 CTA를 사용합니다. 이미지 하단 15%에서 본문색으로 자연스럽게 전환됩니다.

콘텐츠

각진 카드와 에디토리얼 제목 스타일로 콘텐츠형 UI를 확인합니다.

배너

데스크톱은 좌우 경계 15%, 모바일은 상하 경계 15% 범위에서만 이미지가 자연스럽게 섞입니다.

대비 표시

본문의 실제 명암비와 WCAG AA 통과 여부를 미리보기 아래에서 확인합니다.

경계가 선처럼 보이면 브라우저를 강력 새로고침하십시오. Windows Chrome 기준 Ctrl + Shift + R입니다.

7. 테스트 이미지 50장과 배치 검수

상단의 ‘테스트 0/50’을 누르면 과일·야채·한식·양식·중식 각 10장씩 자동으로 분석합니다.

카테고리 구성

과일 10 · 야채 10 · 한식 10 · 양식 10 · 중식 10

빠른 비교

대표색, 표면색, 본문색, 강조색과 텍스트색을 카드별로 비교합니다.

검수 기록

‘승인’ 또는 ‘보정’을 선택하면 현재 프로젝트에 자동 저장됩니다.

원본 출처

리서치 이미지 카드의 Wikimedia Commons 링크에서 원본과 라이선스를 확인할 수 있습니다.

첫 분석 결과는 IndexedDB에 캐시됩니다. 다음 프로젝트에서 같은 무채색 제외 설정으로 불러오면 50장을 다시 계산하지 않고 캐시를 사용합니다.

8. 결과 내보내기

CSS 복사

선택한 한 이미지의 팔레트를 CSS 변수 형태로 클립보드에 복사합니다.

:root {
  --ui-key: #C27637;
  --ui-key-foreground: #151514;
  --ui-gradient-bottom: #D8B99E;
  --ui-text-primary: #151514;
  --ui-accent: #979A17;
}

프로젝트 JSON

분석한 모든 이미지의 원본 데이터, 후보색, 보정 팔레트, 대비값, 검수 상태, 입력 문구와 보정 설정을 하나의 JSON 파일로 저장합니다.

HEX 값을 직접 수정했다면 입력창 밖을 클릭하거나 Enter를 눌러 값을 확정한 뒤 내보내십시오.

9. 프로젝트 저장·복원

업로드 이미지와 분석 결과는 브라우저 IndexedDB에 자동 저장됩니다. 브라우저를 닫거나 PC를 재부팅해도 같은 브라우저와 주소로 다시 접속하면 마지막 프로젝트를 복원합니다.

프로젝트 이름

상단 이름 입력란을 수정하면 프로젝트 이름과 현재 작업이 자동 저장됩니다.

프로젝트 전환

프로젝트 선택 메뉴에서 이전 작업을 골라 이미지와 설정을 다시 불러옵니다.

JSON 백업·복원

‘프로젝트 JSON’으로 백업하고 ‘JSON 불러오기’로 다른 PC나 브라우저에서 복원합니다.

삭제·초기화

‘현재 삭제’는 선택 프로젝트만, ‘전체 초기화’는 모든 프로젝트와 테스트 캐시를 삭제합니다.

자동 저장 상태

상단에 ‘자동 저장 중’ 또는 ‘자동 저장됨’으로 현재 저장 상태가 표시됩니다.

테스트 50장 캐시

첫 분석 결과를 무채색 제외 설정별로 저장하여 다음 실행부터 빠르게 불러옵니다.

시크릿 모드, 브라우저 데이터 삭제, 다른 브라우저·PC에서는 IndexedDB가 이어지지 않습니다. 중요한 작업은 반드시 프로젝트 JSON으로 별도 백업하십시오.

10. 로컬 컴퓨터에서 실행

AI 도구나 API 키는 필요하지 않습니다. Node.js 설치 후 프로그램을 직접 실행할 수 있습니다.

준비물

  • Windows 11, macOS 또는 Linux
  • Node.js 22.13 이상
  • 최초 설치 시 인터넷 연결

GitHub에서 받은 경우

git clone <저장소 주소>
cd ui-color-logic-studio
npm install
npm run dev

명령창에 표시된 로컬 주소를 Chrome에서 엽니다. 일반적으로 http://localhost:5173 형태입니다.

배포용 로컬 빌드

npm run build:local
npm run start
최초 npm install은 패키지를 내려받기 때문에 인터넷이 필요합니다. 설치가 끝나면 직접 업로드한 이미지 분석은 로컬에서 처리됩니다.

11. 문제 해결

이미지를 넣어도 분석되지 않습니다.

JPG·PNG·WebP인지 확인하고, 한 장씩 다시 넣어보십시오. 지나치게 큰 파일은 웹용 크기로 줄이면 안정적입니다.

분홍색 배경인데 텍스트가 검정으로 나옵니다.

오류가 아닙니다. 해당 배경에서는 검정의 대비가 흰색보다 높아 자동 선택된 결과입니다.

그라데이션이 너무 넓습니다.

.photo-bridge의 height: 15%를 조절합니다. 중간 색상점의 퍼센트는 높이가 아니라 색이 변하는 위치입니다.

새 버전이 화면에 반영되지 않습니다.

Windows Chrome에서 Ctrl + Shift + R을 눌러 강력 새로고침하십시오.

저장한 프로젝트가 보이지 않습니다.

이전에 사용한 것과 같은 브라우저 프로필 및 http://localhost:5173 주소인지 확인하십시오. 시크릿 모드나 다른 포트는 별도 저장소를 사용합니다.

AI 프로그램에서만 사용할 수 있습니까?

아닙니다. AI는 로직을 개발하거나 개선할 때만 선택적으로 사용합니다. 완성된 프로그램은 일반 로컬 웹앱으로 독립 실행됩니다.
