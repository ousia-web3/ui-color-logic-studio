개인정보 및 권한 안내

UI 컬러 로직 스튜디오 Chrome 확장프로그램의 이미지 처리와 브라우저 권한 사용 기준입니다.

이미지와 분석 결과는 브라우저 안에서 처리되며 외부 서버, AI 서비스, 광고·추적 도구로 전송되지 않습니다.

데이터 처리

  • 직접 업로드한 이미지, 우클릭으로 선택한 이미지, 사용자가 요청한 화면 캡처만 분석합니다.
  • 프로젝트와 분석 결과는 확장프로그램 전용 IndexedDB에 저장됩니다.
  • 캡처 전달용 임시 데이터는 분석 화면에 전달한 직후 삭제합니다.
  • 확장프로그램을 삭제하거나 Chrome 데이터를 삭제하면 로컬 데이터도 삭제될 수 있습니다.

권한 사용 목적

activeTab사용자가 요청한 현재 웹페이지 화면을 캡처하고 분석 화면으로 돌아올 때만 사용합니다.
contextMenus웹 이미지와 페이지의 우클릭 분석 메뉴를 제공합니다.
storage캡처 이미지를 분석 탭으로 전달하고 직전에 보던 탭을 기억합니다.
unlimitedStorage사용자가 저장한 이미지 프로젝트가 일반 저장 한도로 잘리지 않도록 합니다.
CSS 복사·JSON 저장브라우저의 표준 사용자 동작으로 처리하며 추가적인 전체 사이트 권한을 요구하지 않습니다.
사이트 접근(선택)우클릭한 웹 이미지를 가져올 때 해당 도메인에 대해서만 사용자가 직접 허용합니다.

사용자 제어

프로젝트 JSON으로 백업할 수 있으며 앱의 현재 삭제·전체 초기화 기능으로 저장 데이터를 제거할 수 있습니다. 웹·로컬·Vercel·확장프로그램 저장소는 서로 분리됩니다.
