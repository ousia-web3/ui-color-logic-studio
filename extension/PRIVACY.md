# 개인정보 및 데이터 처리 안내

UI 컬러 로직 스튜디오 Chrome 확장프로그램은 사용자가 직접 선택한 이미지와 화면 캡처를 브라우저 안에서만 처리합니다.

- 이미지, 분석 결과, 프로젝트 데이터는 외부 서버로 전송하지 않습니다.
- AI 서비스, 원격 분석 API, 광고 SDK, 사용자 추적 도구를 사용하지 않습니다.
- 웹 이미지 접근 권한은 사용자가 우클릭 메뉴에서 분석을 요청한 경우에만 해당 이미지 도메인 단위로 요청합니다.
- 현재 탭 캡처는 사용자가 우클릭 메뉴 또는 확장 화면의 캡처 버튼에서 명시적으로 요청한 경우에만 실행합니다.
- 캡처 전달용 데이터는 `chrome.storage.local`에서 분석 탭으로 전달한 직후 삭제합니다.
- 프로젝트와 테스트 캐시는 확장프로그램 전용 IndexedDB에 남으며 사용자가 앱의 삭제·초기화 기능으로 제거할 수 있습니다.
- `unlimitedStorage` 권한은 사용자가 저장한 이미지 프로젝트가 일반 저장 한도로 잘리지 않도록 합니다.
- 확장프로그램을 삭제하면 Chrome 정책에 따라 해당 확장프로그램의 로컬 데이터도 삭제될 수 있습니다.

Chrome 웹 스토어에 공개할 때는 이 문서를 실제 운영 정책 URL로 제공하고, 배포 버전의 권한과 설명이 일치하는지 다시 확인해야 합니다.
