# Chrome 확장프로그램

UI 컬러 로직 스튜디오의 분석 엔진과 저장 기능을 Chrome 확장프로그램에서 그대로 사용합니다. 별도 AI, API 키, 서버가 필요하지 않습니다.

## 빌드 및 설치

사이트의 **Chrome 확장** 버튼으로 ZIP을 내려받거나, 저장소에서 직접 빌드할 수 있습니다.

```bash
npm install
npm run build:extension
```

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 이 저장소의 `extension/dist` 폴더를 지정합니다. ZIP을 받은 경우 먼저 압축을 풀고 그 폴더를 선택합니다.

소스를 수정한 뒤에는 `npm run build:extension`을 다시 실행하고 확장 관리 화면에서 **새로고침**을 누릅니다.

## 사용 방법

- 툴바 아이콘: 전체 스튜디오를 새 탭에서 엽니다.
- 확장 상단 바 → **현재 웹페이지 화면 캡처**: 직전에 스튜디오를 연 웹페이지를 다시 캡처합니다.
- 웹 이미지 우클릭 → **이 이미지로 UI 컬러 분석**: 선택한 이미지를 가져와 바로 분석합니다.
- 페이지 빈 영역 우클릭 → **현재 화면 캡처 후 UI 컬러 분석**: 현재 보이는 탭을 PNG로 캡처해 분석합니다.
- 직접 업로드, 테스트 50장, 프로젝트별 자동 저장, JSON 백업은 웹 버전과 동일하게 동작합니다.

## 저장 범위

확장프로그램의 프로젝트는 해당 Chrome 프로필과 확장프로그램 ID의 IndexedDB에 저장됩니다. 확장프로그램 업데이트와 PC 재부팅 후에도 유지되지만, 확장프로그램 삭제나 Chrome 데이터 삭제 시 함께 제거될 수 있습니다. 웹·로컬·Vercel 버전과 프로젝트를 옮길 때는 프로젝트 JSON 내보내기·불러오기를 사용하세요.

## 권한 설명

| 권한 | 사용 목적 |
| --- | --- |
| `activeTab` | 사용자가 요청한 현재 탭 화면을 캡처할 때만 사용 |
| `contextMenus` | 이미지와 페이지 우클릭 분석 메뉴 제공 |
| `storage`, `unlimitedStorage` | 캡처 전달과 이미지 프로젝트의 안정적인 로컬 보관 |
| 선택한 사이트 접근(선택 권한) | 우클릭으로 고른 웹 이미지를 가져올 때 해당 도메인에 대해서만 요청 |

자세한 내용은 [PRIVACY.md](PRIVACY.md)를 확인하세요.

## 배포 파일

빌드하면 `public/downloads/ui-color-logic-studio-extension.zip`도 함께 생성됩니다. 이 ZIP은 웹 앱의 **Chrome 확장** 버튼에서 내려받을 수 있고, Chrome 웹 스토어 업로드 파일로도 사용할 수 있습니다. 공개 개인정보처리 안내는 `/extension-privacy.html`에 제공됩니다.
